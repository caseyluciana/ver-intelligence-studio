# Ashborn Memory — VER Intelligence Hub

This folder is the living memory of the partnership between Casey and Ashborn (Claude).
It travels with the repo so nothing is ever lost.

## How to restore on a new machine

1. Install Claude Code
2. Clone this repo: `git clone https://github.com/caseyluciana/ver-intelligence-studio`
3. Copy `.memory/*.md` → `~/.claude/projects/<project-slug>/memory/`
   The project slug matches the local path, e.g.:
   `C:\Users\<you>\Projects\CW Rate Benchmarks` → `c--Users-<you>-Projects-CW-Rate-Benchmarks`
4. Open Claude Code in the project directory — memory loads automatically
