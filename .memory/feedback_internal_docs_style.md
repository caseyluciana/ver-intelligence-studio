Use Slack canvas / Slack Surface style for any internal comms doc (proposals, write-ups, briefs, canvases).

**Why:** Corporate memo format (letterhead, To/From/Re grid, signature block) is not how Casey's org communicates. The canvas style is how leadership actually reads and shares things internally.

**How to apply:**
- Use context chips at the top (project · date · audience) instead of a To/From header
- Use icon + small-caps label section headers (📍 The situation, 📊 What I've built, ✅ The ask)
- Write in first person, conversational but substantive
- End with a short footer note pointing to supporting material
- No letterhead, no signature block, no "CONFIDENTIAL" stamp
- Still prints cleanly — just no ceremony
